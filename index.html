III — Process

Three passes through the tray

  1. 01

    Expose

    Your prompt and style are combined into one description and sent to a public image-generation model — nothing is stored on a server tied to you.

  2. 02

    Develop

    The model renders pixels from that description in the frame size you picked. This takes a few seconds, longer the first time a prompt is used.

  3. 03

    Fix

    Once it looks right, save it to your contact sheet or download it directly. Don't like the take — pull another with the same prompt and a new seed.

IV — Before you shoot

Use the darkroom responsibly.

Images are generated by a third-party public model. Don't generate content that depicts real people without consent, that's illegal, or that infringes someone else's rights — the underlying service may reject or filter prompts that violate its own policies.
